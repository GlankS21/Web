## Настройка
Вы можете добавить или изменить учётные записи GitHub следующим образом

1. Перейдите в «Settings» (Ctrl + Alt + S или ⌘ + ,)
2. В строке поиска введите и выберите Version Control -> GitHub.

![Скриншот settings](/image/settings.png)
## Основные Git
#### 1. Commit
Откройте окно «Commit» (Ctrl + K)

![Скриншот](/image/commit.png)

Выберите файлы, которые хотите включить в коммит

Введите краткое сообщение о коммите (обязательно)

![Скриншот](/image/commit2.png)

#### 2. Push
После commit нажмите Ctrl + Shift + K

![Скриншот](/image/commit.png)

В окне Push будут показаны предстоящие обязательства

![Скриншот](/image/push.png)
#### 3. Pull
Pull — это операция загрузки последних изменений из репозитория GitHub. Вы можете это сделать с помощью Crtl + T (Udate Project)

![Скриншот](/image/commit.png)
